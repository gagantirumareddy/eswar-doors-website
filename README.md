# ESWAR DOORS & ALUMINIUM Website

A premium modern business website developed for **ESWAR DOORS & ALUMINIUM**, showcasing PVC doors, aluminium works, and material sales with a responsive dark-themed UI and smooth modern animations.

---

## 🚀 Features

- Premium dark modern UI
- Fully responsive design
- Smooth animations using Framer Motion
- Hero section with branded logo background
- Product & services showcase
- Customer reviews section
- Google Maps integration
- Floating WhatsApp, Phone & Email buttons
- Premium typography and spacing
- Loading screen animation
- Mobile-friendly navigation
- Modern footer and contact section

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- React Icons
